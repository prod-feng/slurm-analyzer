Load additional charts (CPU, GPU, RAM, runtime)
Resource-per-job and RAM/runtime comparisons are bucketed by job start (RAM is requested memory vs recorded MaxRSS where accounting telemetry exists). Runtime is actual elapsed runtime vs Slurm time limit for terminal jobs ending in each bucket. CPU/GPU charts show average allocation per job, not utilization. Disk I/O is shown as unavailable when the accounting data does not provide a reliable value.
Resource values use the selected history range.
Load GPU model GPU-hours share charts
Each pie compares users’ share of GPU-hours for one GPU model. Models are discovered from current scontrol node inventory and accounting records; generic GPU allocations are inferred from the job node list when possible.

Load resource usage charts by account hierarchy level
Each level begins on a new line. Charts compare accounts at the same depth; parent and child levels are not mixed. Task totals are summed NTasks across jobs; data-read/data-write are summed MaxDiskRead/MaxDiskWrite in GiB.
