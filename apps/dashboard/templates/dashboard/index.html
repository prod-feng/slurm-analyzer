Resource-per-job and RAM/runtime comparisons are bucketed by job start (RAM is requested memory vs recorded MaxRSS where accounting telemetry exists). Runtime is actual elapsed runtime vs Slurm time limit for terminal jobs ending in each bucket. CPU/GPU charts show average allocation per job, not utilization. Disk I/O is shown as unavailable when the accounting data does not provide a reliable value.
Resource values use the selected history range.
“Unknown” means the historical Slurm job accounting record has no account value; it is not a current Slurm account.
Department and PI charts include descendant projects; project chart shows individual projects.

Resource usage share by account level

Each level begins on a new line. Charts compare accounts at the same depth; parent and child levels are not mixed. Task totals are summed NTasks across jobs; data-read/data-write are summed MaxDiskRead/MaxDiskWrite in GiB.
Parent
Aggregated CPU-hours and GPU-hours for terminal jobs started in the selected history range. Node/task counts are reported where Slurm accounting provides them.
When sacct records a comma-separated list of eligible partitions, the job is shown under each named partition; CPU/GPU-hours are divided evenly among those alternatives so the chart does not double-count total resource-hours. Job counts are inclusion counts and can overlap across partitions.
